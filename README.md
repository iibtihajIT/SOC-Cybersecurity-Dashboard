# SOC Cybersecurity Dashboard

An interactive Power BI dashboard for monitoring and analyzing security incidents within a Security Operations Center (SOC).

## Overview
This dashboard tracks and visualizes key cybersecurity metrics to help security teams identify threats, monitor incident trends, and make faster, data-driven decisions.

## Key Features
- **Total Incidents & Trends** – Monthly incident tracking with year-over-year comparison (2023 vs 2024)
- **Average Response Time** – Tracks how quickly incidents are resolved
- **Data Breaches** – Monitors breach count and year-over-year change
- **Incidents by Severity** – Classification into Low, Medium, High, and Critical
- **Attack Source Analysis** – Breakdown by country and geographic region
- **Threat Group Analysis** – Identifies attacking groups (e.g., APT28, APT41, Lazarus)
- **Critical Incident Log** – Detailed log of high-impact incidents with department, division, and resolution time

## Tools & Skills Used
- Power BI
- Data Analysis
- Data Visualization
- DAX (Data Analysis Expressions)
